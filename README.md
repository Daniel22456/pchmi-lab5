# ЛР №5 ПЧМИ — прототип интерфейса и его тестирование

Прототип информационной системы сопровождения государственных закупок
(экранные формы F1–F12) с модулем фиксации событий и режимом тестирования.

Дисциплина: «Проектирование человеко-машинного интерфейса».
Автор: Саяхов Д. Р., гр. ИВТ-ПО-302Б.

## Как пройти тест

1. Откройте прототип: **https://daniel22456.github.io/pchmi-lab5/**
   (или скачайте репозиторий и откройте `index.html` в браузере).
2. Нажмите **«Начать тестирование»**, укажите уровень владения ПК и опыт.
3. Выполните 6 заданий. Перед каждым показывается его текст; когда закончите —
   кнопка **«Готово»** в бордовой полосе сверху. Если не получается — «Не могу выполнить».
4. В конце нажмите **«Скачать лог-файл (CSV)»** и отправьте файл автору.

Тест занимает 5–10 минут. Имя не записывается, используется код испытуемого.
Все данные в прототипе условные.

## Состав репозитория

| Файл | Назначение |
|---|---|
| `index.html` | Прототип (HTML, CSS, JavaScript в одном файле) с модулем фиксации событий |
| `analyze_log.py` | Модуль анализа лог-файла: время по шагам и заданиям, сравнение с оценкой GOMS |
| `walkthrough.py` | Проверочный прогон всех заданий по оптимальному пути (Playwright) |
| `logs/` | Образцы лог-файла в форматах CSV, JSONL и PLAIN TEXT (проверочный прогон) |
| `logs/ai_runs/` | Пять прогонов ИИ-ассистента (синтетические данные для функциональной проверки, не тестирование с людьми) |

## Журнал событий

Каждое действие пользователя записывается с отметкой времени. Поля записи:
`timestamp, actor_id, actor_role, action, object_type, object_id, outcome, changes, context`.
Выгрузка — в CSV, JSONL или PLAIN TEXT (ссылка «Журнал событий» внизу страницы).

## Анализ лог-файлов

```bash
python analyze_log.py logs/ --out result      # сеансы испытуемых
python analyze_log.py logs/ --all             # вместе с проверочным прогоном
```

Скрипт читает все три формата, определяет время выполнения каждого задания и шага
и сравнивает его с теоретической оценкой по методике GOMS (KLM).

Оценка GOMS, с: T1 — 32,90; T2 — 18,00; T3 — 25,12; T4 — 8,80; T5 — 21,80; T6 — 12,70.
